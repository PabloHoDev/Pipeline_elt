# Pipeline_elt
ETL é um processo padrão em dados:  E — Extract (Extrair) Buscar dados de uma fonte (CSV, Excel, banco, API)  T — Transform (Transformar) Limpar, padronizar, validar e enriquecer os dados  L — Load (Carregar) Salvar os dados tratados para uso (CSV final, banco, BI)  📌 Esse processo existe em praticamente toda empresa orientada a dados.
